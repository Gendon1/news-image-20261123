# The World in One Day — 23 November 2026

A newspaper front-page poster summing up the world news of Monday, 23 November 2026,
frozen into a single image. Six headlines, one day, one spread.

## The six stories

- Nvidia reinstates Jensen Huang as CEO after Trump intervention; shares jump about 30 percent.
- Ukraine sinks a Russian warship off Libya, confirmed by Zelensky, near Benghazi.
- COP31 climate talks end with no deal.
- NATO warns Russia in Berlin.
- A factory fire in Indonesia kills at least 24 people.
- Iran vows to break a US blockade.

## How to run

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` — the same file as the one in this repo.
